# 页面清单与流程

## 1. 用户端页面清单

1. 首页：服务分类、热门套餐、快速下单入口、纪念馆入口、客服入口。
2. 服务列表页：按代祭扫、跑腿、咨询、纪念馆分类展示。
3. 服务详情页：服务说明、价格、履约内容、注意事项、退款规则、可选附加项。
4. 需求提交页：适用于询价和预约类服务，填写地点、时间、联系人、具体需求。
5. 订单确认页：确认服务项、联系人、预约时间、附言、金额。
6. 支付页：定金、尾款或全款支付。
7. 订单列表页：全部、待支付、待服务、服务中、已完成、售后中。
8. 订单详情页：订单节点、代办员信息、履约凭证、联系客服、申请售后。
9. 履约凭证页：查看照片、视频、时间水印、服务说明。
10. 纪念馆首页：逝者列表、纪念日提醒、创建纪念馆入口。
11. 纪念馆详情页：生平简介、照片、留言、祭拜记录、家庭成员共管。
12. 个人中心：联系人管理、地址管理、发票、客服、协议、实名认证。

## 2. 代办员端页面清单

1. 登录与实名认证页：身份证、人脸、银行卡、服务区域、擅长服务。
2. 首页：待接单数、今日任务、收入概览、消息通知。
3. 接单大厅：按距离、区域、服务类型展示可接订单。
4. 任务详情页：用户需求、地点、时间、备注、报价信息、联系人。
5. 到场打卡页：定位、时间、水印照片。
6. 履约上传页：分阶段上传照片视频和说明。
7. 异常上报页：天气异常、墓园关闭、用户需求变更、额外费用申请。
8. 任务完成页：提交完成说明，等待用户确认。
9. 收入结算页：待结算、已结算、申诉记录。
10. 个人中心：资料、评级、培训、服务规范、处罚记录。

## 3. 后台管理端页面清单

1. 控制台：订单量、成交额、服务完成率、投诉率、城市数据。
2. 服务管理：分类、套餐、价格模板、附加项、服务说明。
3. 订单管理：筛选、查看详情、派单、改单、取消、售后处理。
4. 报价管理：报价审核、人工改价、报价模板。
5. 代办员管理：入驻审核、等级、区域、排班、考核、冻结。
6. 内容审核：纪念馆资料、留言、图片视频审核。
7. 财务结算：订单流水、支付、退款、分账、代办员结算。
8. 客服仲裁：投诉工单、凭证查看、退款裁定。
9. 权限管理：运营、客服、财务、管理员角色权限。
10. 配置中心：城市站点、通知模板、协议、敏感词、节假日规则。

## 4. 主流程

### 4.1 标准服务流程

首页选服务 -> 服务详情 -> 下单支付 -> 后台派单 -> 代办员接单 -> 到场打卡 -> 上传履约凭证 -> 用户确认 -> 结算完成。

### 4.2 询价服务流程

提交需求 -> 后台或代办员报价 -> 用户确认并支付 -> 派单履约 -> 完成与结算。

### 4.3 敏感咨询流程

提交预约需求 -> 后台审核 -> 客服确认 -> 安排时间与人员 -> 支付 -> 服务交付 -> 回访。

### 4.4 售后流程

用户发起售后 -> 后台调取履约凭证 -> 客服仲裁 -> 退款或驳回 -> 结案。

### 4.5 纪念馆流程

创建纪念馆 -> 填写资料上传内容 -> 后台审核 -> 对外展示或家庭私密展示 -> 家属留言互动。
