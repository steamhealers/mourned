# 白事服务小程序 PRD

## 1. 产品定位

做一个白事服务相关的微信小程序平台，首发包含用户端小程序、代办员端小程序、后台管理端。用户端和代办员端都按微信小程序上线，但前端技术必须保留 uni-app 能力，保证后续可以平滑扩展到 H5、App 或其他小程序平台。

## 2. 目标用户

1. 异地不能亲自到场祭扫的家属。
2. 正在处理白事、需要跑腿或流程协助的家庭。
3. 需要咨询选墓、礼仪、流程安排的人群。
4. 需要为亲属建立线上纪念空间的家庭成员。

## 3. 核心价值

1. 把线下不透明、碎片化、依赖熟人的白事服务，做成可下单、可追踪、可存证的平台服务。
2. 把高频标准服务做成交闭环，把非标服务做成询价闭环，把敏感服务做成预约审核闭环。
3. 用履约凭证和后台仲裁降低纠纷。

## 4. 服务分层

### 4.1 标准化可直接下单

- 代祭扫
- 代上坟
- 墓位清洁
- 鲜花供品代购
- 祭品摆放
- 拍照视频回传
- 白事用品跑腿配送

### 4.2 半标准化先询价后确认

- 白事咨询
- 治丧流程协助
- 灵堂用品代办
- 接送车协调
- 材料代跑
- 墓园陪同

### 4.3 敏感服务预约审核

- 风水咨询
- 选墓咨询
- 迁葬咨询
- 礼仪咨询

此类服务不直接自动成交，必须经过人工审核和客服确认。

### 4.4 内容型服务

- 线上纪念馆
- 云祭扫
- 祭日提醒
- 家庭共祭
- 留言祈福

## 5. 三端范围

首版范围以交易闭环为准，只覆盖标准下单、询价报价、后台派单、代办员履约、售后处理、财务结算。

纪念馆、云祭扫、内容审核、消息通知、实名审核等能力不进入首版开发，放到后续阶段。

### 5.1 用户端

浏览服务、下单、询价、支付、查看进度、查看履约凭证、申请售后。

### 5.2 代办员端

接单、查看任务、到场打卡、上传照片视频、完成履约。

### 5.3 后台管理端

服务管理、订单调度、报价审核、代办员审核、售后仲裁、财务结算。

## 6. 交易模型

1. 直接下单：适用于代祭扫、清洁、代购等标准服务。
2. 询价确认：用户先提交需求，平台或代办员报价，用户确认后支付。
3. 预约审核：用户提交时间、地点、需求说明，后台审核通过后安排咨询。

## 7. 订单主状态

首版订单状态以当前代码实现为准，统一为以下 9 个状态值。

| 状态值 | 中文说明 | 触发场景 |
| --- | --- | --- |
| pending_quote | 待报价 | 用户提交询价类订单后进入 |
| pending_payment | 待支付 | 用户确认报价后进入 |
| pending_dispatch | 待派单 | 直接下单完成或支付完成后进入 |
| in_service | 服务中 | 后台派单且代办员接单后进入 |
| pending_confirm | 待用户确认完成 | 代办员提交完结后进入 |
| completed | 已完成 | 用户或后台确认完结后进入 |
| refund_in_progress | 售后中 | 用户发起退款申请后进入 |
| refunded | 已退款 | 退款审核通过并完成退款后进入 |
| closed | 已关闭 | 订单被后台关闭或退款驳回后关闭 |

### 7.1 状态迁移

标准订单主链路：

pending_dispatch -> in_service -> pending_confirm -> completed

询价订单主链路：

pending_quote -> pending_payment -> pending_dispatch -> in_service -> pending_confirm -> completed

售后链路：

in_service 或 pending_confirm 或 completed -> refund_in_progress -> refunded 或 closed

补充说明：

1. 首版不保留“待提交”“待接单”等独立状态，统一折叠进现有工程状态。
2. “待用户确认”在首版拆成两段：报价确认对应 pending_payment，完结确认对应 pending_confirm。
3. 后台若需人工结束异常订单，统一落到 closed。

## 8. 售后与风控规则

1. 未派单前可直接退款。
2. 已派单未到场，按规则扣除基础服务费后退款。
3. 已到场但未完成，按实际履约节点进行部分退款。
4. 所有争议以时间、地点、水印凭证、沟通记录为主要仲裁依据。
5. 纪念馆内容、图片、留言必须经过内容审核。
6. 风水、选墓等敏感服务禁止承诺结果，文案统一规范为咨询建议类服务。

## 9. MVP 建议

1. 先上线代祭扫、跑腿代办、咨询报价。
2. 首版只实现交易闭环，不包含纪念馆、内容审核、消息通知、实名认证审核。
3. 第二阶段上线线上纪念馆和云祭扫。
4. 第三阶段上线风水选墓类预约服务。
